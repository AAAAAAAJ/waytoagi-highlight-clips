# 前 3 秒与后文兑现

## 先讲清楚这是什么

前 3 秒先建立理解：第一次看到的观众能说出“这是什么、能做什么或这段在讲什么”。开头主标题用“具体对象或内容类型 + 一个功能、动作或主题”；对应的真实画面从第一帧出现。标题可以稳定展示整个开头，无需为了卡秒数频繁切字。

- 工具或方法：写出类别和用途，如“阅读笔记工具｜点笔记跳回原文”。工具名可放来源栏，陌生名称旁补类别。
- 作品或案例：写清作品形态和实际变化，如“声音驱动的城市动画｜楼群随声音变化”。网上案例、创作练习等性质在首屏可读。
- 观点或段子：写明主题和内容类型，如“AI 职场段子｜老板嫌文案 AI 味重”，保留必要铺垫和收尾。
- 主标题中的“这个、它、太强了、效果怎么做”等表达需要明确指代；让关键对象出现在大字标题中。Logo 和来源小字承担署名功能。

优先选原片中已经讲清主题的完整句子作为开场。原声从操作中途开始时，可用编辑标题补齐已核实的对象和用途；字幕忠实记录实际原声。编辑标题与逐字字幕保持分区，不把新增介绍写成讲者原话。只有名称、用途或来源尚不清楚时，先核对素材再写。

在清楚的主题上增加一个具体看点，后文展示相应证据；避免连续抛悬念却让观众猜内容。以下例句均为结构示例，只有素材确实支持时才使用。

## 留存数据的用途

开头方案是编辑假设，需要结合本条素材与留存数据判断。TikTok 的创意指南强调尽早用悬念、意外或情绪抓住注意力；这类广告建议不能直接换算成其他平台的自然流量或完播提升。[TikTok Creative Codes](https://ads.tiktok.com/business/en-US/creative-codes)

YouTube 留存工具分别展示开头留存、观看高点、回看尖峰和流失低点；Intro 指标观察前 30 秒。不同平台的口径需要分别读取。[YouTube 留存说明](https://support.google.com/youtube/answer/9314415?hl=en)

## 一条视频只承诺一个看点

剪辑表记录：一句话主题、开头标题、可见证据、后文兑现时间、来源属性。标题尽量一眼读完，以手机实际可读性为准；必要时分成“对象或类别”“用途或看点”两行。

| 类型 | 编辑标题示例 | 第一屏 | 后文兑现 |
|---|---|---|---|
| 创作结果 | 声音驱动的城市动画｜楼群随声音变化 | 城市动画与声音响应 | 录音、调节与样式变化 |
| 实用方法 | 用参考图做视觉设计｜先给3张图 | 参考图和对应产物 | 参考图怎样影响制作 |
| 趣味原话 | AI职场段子｜老板嫌文案AI味重 | 对应原声与段子类型说明 | 保留段子铺垫与收尾 |
| 能力测试 | AI生成CAD图纸｜看看能否直接用 | 真实出图结果与工具信息 | 保留精度与可用性评价 |
| 交互演示 | 阅读笔记工具｜点笔记跳回原文 | 点击与原文定位 | 展示记录、返回和定位 |
| 网上案例 | AI画板肖像案例｜看它一笔笔画出来 | 参考照片、笔触与作者署名 | 展示过程，标明网上来源 |

例句随事实改写。模拟网页深度、创作练习、已有插件优化等性质必须准确保留。

## 开场操作

1. 结果画面前置：先用主标题说明对象和用途；原声能独立理解时，前 2–3 秒配本条稍后的真实结果，随后回到操作；补充画面单独记录来源。
2. 原话前置：开头问候或找窗口占用注意力，片内又有自洽精彩原话时，从该句开始。同步重排声音和字幕，检查断词、指代和重复笑点。
3. 问题与证据同屏：画面已是核心演示时，保留连续原声，上方标题同时写清对象和具体问题，字幕继续呈现原话。
4. 前后状态：原片确有输入和结果时，用可识别的变化开场；保持真实先后含义。

无需固定三秒一换。鼠标动作、模型旋转、空间变化和声音反馈本身可以构成进展。

## 后文承接

- 开场后补充操作所需的一项背景，随后展示动作或证据；对象和用途在前 3 秒已经交代。
- 片长前半段开始兑现，后半段补充变化、方法或限制。真实完成结果可适当停留。
- 结尾完成本条主张。用户需要互动引导时，再加与内容直接相关的问题。

## 检查与迭代

先静音只看前 3 秒，不借助视频外的发布标题，回答“这是什么、能做什么或在讲什么”。只能复述工具名、悬念或“很厉害”时，重写主标题或重选开场。再连听原声，确认与主题相符。

看 0 秒、1.5 秒、2.9 秒、回到正叙处和兑现点：主题清楚、文字可读、字幕原声一致、没有加载空白或无关窗口。去口癖或删铺垫后重新做此检查，避免连同必要介绍一起删除。

有账号数据时记录平台的初始留存、平均观看时长和完整观看指标，找具体流失点。比较同类内容和相近片长；对比开头版本时优先只改一个变量，保留版本文件，同时考虑发布时间和受众差异。
