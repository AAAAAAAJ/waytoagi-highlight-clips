# 前 3 秒与后文兑现

## 一条视频只承诺一个看点

剪辑表记录：开头标题、可见证据、后文兑现时间、来源属性。标题尽量一眼读完，以手机实际可读性为准。

| 类型 | 编辑标题示例 | 第一屏 | 后文兑现 |
|---|---|---|---|
| 创作结果 | 这座城市，跟着声音动 | 城市与声音响应 | 录音、调节与样式变化 |
| 实用方法 | 审美说不清？先给3张图 | 参考图和产物 | 参考图怎样影响制作 |
| 趣味原话 | 老板说：AI味太重了 | 原话对应文本 | 保留段子铺垫与收尾 |
| 能力测试 | 能出CAD，实际能用吗 | 真实出图结果 | 保留精度与可用性评价 |
| 交互演示 | 点一下笔记，回到原文 | 点击与原文定位 | 展示记录、返回和定位 |
| 网上案例 | AI在画板里一笔笔画肖像 | 参考照片、笔触与署名 | 展示过程，标明网上来源 |

例句随事实改写。模拟网页深度、创作练习、已有插件优化等性质必须准确保留。

## 开场操作

1. 结果画面前置：原声能独立理解时，前 2–3 秒配本条稍后的真实结果，随后回到操作；补充画面单独记录来源。
2. 原话前置：开头问候或找窗口占用注意力，片内又有自洽精彩原话时，从该句开始。同步重排声音和字幕，检查断词、指代和重复笑点。
3. 问题与证据同屏：画面已是核心演示时，保留连续原声，上方标题换成具体问题，字幕继续呈现原话。
4. 前后状态：原片确有输入和结果时，用可识别的变化开场；保持真实先后含义。

无需固定三秒一换。鼠标动作、模型旋转、空间变化和声音反馈本身可以构成进展。

## 后文承接

- 开场后紧接理解问题所需的一项背景，随后展示动作或证据。
- 片长前半段开始兑现，后半段补充变化、方法或限制。真实完成结果可适当停留。
- 结尾完成本条主张。用户需要互动引导时，再加与内容直接相关的问题。

## 检查与迭代

看 0 秒、1.5 秒、2.9 秒、回到正叙处和兑现点：主题清楚、文字可读、字幕原声一致、没有加载空白或无关窗口。

有账号数据时记录平台的初始留存、平均观看时长和完整观看指标，找具体流失点。比较同类内容和相近片长；对比开头版本时优先只改一个变量，保留版本文件，同时考虑发布时间和受众差异。
