# 竖屏高光品牌样式参考

## 当前视觉基准

采用灰白底、黑色大标题、彩色块点缀；黑色页眉承载用户提供的原版 Logo。画面、解说和字幕分区清楚，装饰不覆盖操作内容。以下坐标来自当前渲染实现，基准画布为 `1080 × 1920`。

| 角色 | 色值 |
| --- | --- |
| 主背景 | `#EFEFEF` |
| 正文与标题 | `#111111` |
| 次要文字 | `#555555` |
| 页眉 | `#080808` |
| 页眉主字 / 次字 | `#FFFFFF` / `#B8B8B8` |
| 第二行标题底色 | `#D4FF70` |
| 字幕面板 | `#FFFFFF` |
| 分类竖条 / 字幕竖条 | `#FF4900` / `#C18EFF` |
| 视频细边 / 页脚分隔线 | `#777777` / `#888888` |
| 页脚六色块 | `#FF4900`、`#D4FF70`、`#DEC7E2`、`#00C0FF`、`#00A158`、`#C18EFF` |

彩色装饰采用实心矩形和细竖条，字幕面板保持方角。默认采用浅色主题；制作黑底版本时，一起调整背景、正文、次字与面板色。

## 布局坐标与字号

文字位置使用左上锚点。字体大小以下均为基准画布上的像素值。

| 区域 | 实际布局 |
| --- | --- |
| 页眉 | 黑色矩形 `(0,0)—(1080,208)`；栏目名 `(751,94)`、26 px；编号 `(751,141)`、22 px |
| 原 Logo | 按完整 RGBA 画布等比缩到宽 530，置于 `(22,36)`；透明边距保留 |
| 分类 | 橙色条 `(72,243)—(79,279)`；标签 `(98,247)`、26 px |
| 主标题第一行 | `(72,315)`、72 px |
| 主标题第二行 | `(72,407)`、72 px；底色框 `(63,399)—(90+文字实测宽度,485)`，字色固定为深黑 |
| 背景或来源标签 | `(74,514)`、27 px；多来源时按片内时段切换，未被标签占用的时段恢复背景说明 |
| 视频画面 | 外边 `(39,549)—(1041,1361)`；实际内容框左上 `(40,550)`、宽 1000、高 810 |
| 讲者与内容类型 | `(72,1394)`、29 px、次要文字色 |
| 字幕框 | `(60,1470)—(1020,1650)`；左侧紫条宽 7；字幕中心 `(540,1560)`、52 px，最多两行 |
| 看点 | 标签 `(74,1700)`、22 px；正文 `(172,1696)`、30 px |
| 页脚 | 分隔线 `(74,1760)—(1006,1760)`、2 px；行动文案 `(74,1790)`、29 px；日期/系列说明 `(74,1850)`、22 px |
| 彩色阶梯 | 第 `j=0..5` 块左边 `790+36j`，顶部 `1840-11j`，右边为左边加 35，底部 1868 |

视频框以 `overlay=40:550`、`1000×810` 参数为准。

## 字体与文字约束

- 当前字体为 `Hiragino Sans GB.ttc`；标题 72 px 使用字体集合 `index=2`，其余小于 65 px 的文字使用 `index=0`。ASS 字体名为 `Hiragino Sans GB`，字幕 52 px。
- 移植到其他环境时把字体文件、集合索引和 ASS 字体名配置化。先确认中文与拉丁字形可用，再用实际加载的字体重新测量和渲染；替换字体后不要沿用旧换行结果。
- 字幕以实际像素宽度换行，最大行宽 884；按完整英文/数字词组和中文字符分词，最多两行。ASS 使用画布 `PlayResX=1080`、`PlayResY=1920`、中心对齐、`pos(540,1560)`，左右 margin 为 90。
- 标题固定两行。先改短标题，再调整字体；第二行底色宽度跟随字体实测结果，检查右边界及留白。案例主题、讲者、产品名、来源、日期、栏目、编号与口号均由任务配置传入。

## Logo、裁切与缩放不变量

- 使用用户提供的原 Logo，保持字形、色彩、纵横比与透明边距；不要另画彩虹、重新排品牌字，或用相近字体替代 Logo 字标。
- 当前原素材为 `1268×405` 的 RGBA 图，非透明区域约为 `(120,93)—(1123,294)`。完整图缩到 `530×169` 后放在 `(22,36)`，可见图形约落在 `(72,75)—(491,159)`。裁掉透明边后继续用 530 宽会改变视觉大小，必须同步重算可见边界。
- 源视频先按原帧像素 `crop=[x,y,w,h]` 裁切，再用 `scale=1000:810:force_original_aspect_ratio=decrease` 等比缩放，居中补黑边，最后 `setsar=1`。保留真实宽高比，避免界面、人物、圆形和 Logo 变形。
- `segment_crops` 与 `keep` 一一对应；独立补充画面可以指定自己的 `crop`。同一画面涉及“原文+笔记”“画作+参考照片”“控制项+结果”时，优先保留这些关系，再决定放大程度。
- 画布换为同一比例的其他尺寸时，所有坐标、字号、线宽、留白一起按统一系数缩放；换宽高比时重新布局，禁止仅把横纵坐标分别拉伸。

## 安全区、封面与换品牌

- 当前普通文字左右约留 72 px，字幕面板左右留 60 px，视频左右留 40 px；关键标题、来源标签与字幕均独立于页脚装饰。指定发布平台后叠加其 UI 安全区蒙版，确认互动按钮和文案区不遮挡关键信息。
- 缩到手机预览尺寸检查：两行标题、字幕、作者与工具来源仍应可辨认；演示框中的关键按钮、读数、标注和操作结果应能看清。小字过多时缩短文案或改变裁切。
- 封面复用成片版式，选清晰结果帧。保持 `9:16` 比例；文档内缩略图可等比显示为 `360×640`，不能只改其中一边造成拉伸。
- 换品牌时替换 Logo、品牌色角色、栏目名、口号及字体配置；保留“标题—来源—实际演示—字幕—看点”的层次。新 Logo 依据其透明边距、可见面积和适合的底色重新测量，页眉高度与旁边文字让位需一起检查。
- 新样式先渲染短标题、长中文标题、含英文产品名标题、两行字幕、多来源标签各一种。确认无溢出、遮挡或变形后再批量渲染。
