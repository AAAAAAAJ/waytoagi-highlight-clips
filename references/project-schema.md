# 项目 JSON：schema_version 1

入口：`python3 scripts/render_clips.py --project /path/to/project.json`。需要 Python 3、Pillow，以及 PATH 中可调用的 `ffmpeg`、`ffprobe`。当前预设为 `waytoagi-light`：1080×1920，黑色品牌页眉、灰白背景、黑字和彩色块。Logo 保持原始比例。

```bash
python3 scripts/render_clips.py --project project.json --validate-only
python3 scripts/render_clips.py --project project.json --clip 01 --clip 03
python3 scripts/render_clips.py --project project.json --clip 01 --sample 8
```

`--clip` 可以重复；省略时渲染全部条目。`--sample N` 只渲染各条开头 N 秒，短于 N 秒的条目按实际长度输出。`--validate-only` 读取源视频元信息并检查项目，不创建目录或写文件。错误返回退出码 1；成功返回 0。

## 顶层字段

所有项目内路径均相对 **项目 JSON 所在目录** 解析，也接受绝对路径。视频和字体路径可以包含空格、中文或撇号；脚本采用参数数组调用 FFmpeg，过滤器与 ASS 在独立 job 目录中通过短文件名引用。

| 字段 | 类型 / 默认值 | 说明 |
|---|---|---|
| `schema_version` | 必填整数 `1` | 当前唯一支持版本 |
| `source` | 必填字符串 | 唯一源视频，必须同时具有音视频轨道 |
| `output_dir` | 必填路径 | 正式 MP4、字幕和封面目录 |
| `work_dir` | 必填路径 | 中间结果、归一化项目、日志和样片目录 |
| `event.name` | 必填字符串 | 右上角活动名称及底部来源说明 |
| `event.date` | 必填字符串 | 底部显示日期，按提供的文本显示 |
| `event.footer` | 必填字符串 | 底部行动文案 |
| `style.preset` | `waytoagi-light` | 当前唯一预设 |
| `style.logo` | 可选路径 | 默认技能内 `assets/brand-logo-white.png` |
| `style.font` | 可选路径 | 中文 TTF/OTF/TTC；省略则查找系统已知中文字体 |
| `style.font_bold_index` | 可选非负整数 | 字体集合中的标题字重索引；Hiragino Sans GB 默认 `2`，其他字体默认 `0` |
| `fps` | 整数，默认 `25` | 可设为 1—60；默认输出 25 fps |
| `clips` | 非空数组 | 每个条目是一条独立成片 |

`output_dir` 与 `work_dir` 必须是独立、互不包含的目录，也不能直接使用项目目录。源视频若含旋转元信息，应先整理为方向明确的视频，再确定裁切坐标。

## 单条 clip

| 字段 | 类型 / 默认值 | 说明 |
|---|---|---|
| `id` | 必填字符串 | 1—48 个 ASCII 字母、数字、下划线或短横线，以字母或数字开头；项目内唯一 |
| `name` | 必填字符串 | 展示名称可含 CAD/3D 等文字；文件系统特殊字符会替换为下划线，截至 90 字符并限制 `id_name` 不超过 220 UTF-8 字节 |
| `tag` | 必填字符串 | 上方小分类，如“建筑实测” |
| `headline` | 必填两元素字符串数组 | 常规标题的两行文本 |
| `context` | 必填字符串 | 视频上方的工具、案例或来源说明 |
| `speaker` | 必填字符串 | 讲者署名 |
| `kind` | 必填字符串 | “现场演示”“案例解读”等性质说明 |
| `takeaway` | 必填字符串 | 下方“看点”文案 |
| `hook` | 可选字符串 | 保留的编辑提示，不自动替代标题；可见开场标题使用 `opening_hook` |
| `source_start` / `source_end` | 必填秒数 | 相对完整源视频的窗口起止时间 |
| `keep` | 必填 `[[start,end],…]` | **相对源窗口起点** 的保留区间，按顺序拼接 |
| `crop` | 默认完整源帧 | `[x,y,width,height]`，按源视频像素 |
| `segment_crops` | 可选数组 | 每个 keep 对应一个 crop；条目为 `null` 时使用默认 crop |
| `captions` | 可选数组，默认 `[]` | 内嵌字幕，见下一节 |
| `caption_timebase` | 默认 `window` | 仅接受 `window` 或 `output` |
| `broll` | 可选数组 | 真实源画面的替换或明确标记的冻结画面 |
| `labels` | 可选数组 | 在输出时间轴内替代 context 的来源/工具标签 |
| `cover_output_time` | 默认开头 3 秒内 | 封面取帧的**成片时间**，必须早于成片结束 |
| `opening_hook` | 可选对象 | `{"text":"主题标题","duration":3}`，见开场规则 |

`keep` 按数组顺序播放，可重排和重复源区间，例如 `[[4,6],[0,8]]` 会先播放 4—6 秒的原声预告，再播放 0—8 秒正文。每个区间均须位于窗口内。端点必须落在 `1/fps` 秒网格；25 fps 时为 0.04 秒网格。脚本会明确拒绝未对齐的输入，编辑者应先决定取舍再对齐，脚本不会悄悄改变切点。相邻区间可以连续，例如 `[0,2]` 和 `[2,4]`。

crop 坐标及宽高必须为偶数，且在源帧范围内。画面等比缩放至 1000×810 显示区，余下空间补黑边，不会拉伸变形。

## 字幕与剪辑区间

每条字幕为：

```json
{"start": 0.12, "end": 2.56, "text": "可核对的原声字幕", "editorial": false}
```

`editorial` 为可选布尔标记，表示编辑者已将这条内容标记为编辑文案；它不会放宽时间覆盖校验，也不会自动添加或修改原文。开场主题请使用 `opening_hook`，以便继续保留原声字幕。

- `window`：起止相对 `source_start`。字幕必须完整落在源保留区间的并集内。只有成片时间与源时间均相邻连续的字幕碎片才合并为一个事件。重复播放同一源句时生成独立的字幕事件，例如 `keep=[[4,6],[0,8]]` 的 `[4,6]` 字幕分别映射到成片 `[0,2]` 和 `[6,8]`。
- 如果字幕跨越被删除的时间间隔，或者完全位于删除区域，脚本报出条目索引、文字和缺失区间。编辑者需要按保留语音切分或重写字幕，再提交；不得仅缩短原句的时间码来掩盖删除的词。
- 每一次重复出现都须覆盖完整字幕。预告只截取一句话的中部时，需要按实际保留词语拆分原字幕；后面完整的正文不能补齐前置片段被删掉的词，脚本会单独报出该次不完整出现。
- `output`：起止已经是拼接后的成片时间，脚本检查范围和重叠，原声内容是否对应由编辑者负责核实。
- 字幕按时间排序，禁止重叠；文本自动换行，最多两行，必要时从 52 px 缩至 40 px。仍放不下时要求人工拆句。
- 采样模式的 SRT 会裁到样片长度；完整项目字幕仍保存在归一化项目中。
- 字幕区固定在视频下方。ASS 控制字符通过全角形式显示，防止字幕文本被误解释为排版指令。

例：`keep=[[0,2],[2,4]]` 中的 `[1,3]` 字幕可直接保留；`keep=[[0,2],[3,4]]` 中的 `[1,3.5]` 会明确报错，因为 `[2,3]` 的语音被删除。

## B-roll 和来源标签

B-roll 仅使用顶层 `source`，本版本不接受外部素材路径。B-roll 只替换画面，剪好的原声音轨和字幕保持原时间轴。

```json
{
  "at": 0,
  "duration": 2.76,
  "source_start": 4309.12,
  "crop": [0,144,1584,872],
  "freeze": false
}
```

`at` 为成片起点，`duration` 为持续时间，`source_start` 为完整源视频中的绝对秒数。条目按 at 递增，不可重叠或超出成片。`crop` 可省略，继承 clip.crop。`freeze:true` 取该源时刻的一帧并保持指定时长，画面会显示“画面定格”，避免将定格包装为连续操作。不得用冻结帧证明操作速度。

标签用于明确区分多个作者或工具，显示在视频框上方，不遮挡原声字幕：

```json
{"output_start":0,"output_end":18.6,"text":"网上案例 ① 作者 · 工具"}
```

标签按时间递增，不得重叠，间隙自动恢复 clip.context。作者和工具应依据原始页面核对。

## 开场主题标题

```json
{"opening_hook":{"text":"建筑模型\n可以直接进去逛","duration":3}}
```

前 3 秒仅替换上方两行 headline 区域；随后恢复普通 headline。短片短于设定时长时覆盖至片尾。支持显式换行或自动换成最多两行，不覆盖视频、来源标签或原声字幕。主题文案和 B-roll 由编辑者提供：脚本不会生成结果画面，也不会判断其是否支持标题中的断言。

## 输出与中间产物

正式渲染输出：

- `output_dir/<id>_<name>.mp4`：1080×1920，H.264、AAC 48 kHz、160 kbps，默认 25 fps，faststart。
- `output_dir/字幕/<id>_<name>.srt`。
- `output_dir/封面/<id>_<name>.jpg`：从实际成片取帧，显式使用全范围 JPEG 像素格式。

样片独立位于 `work_dir/samples/`，文件名含秒数和 `sample`，并有各自字幕、封面；不会创建或替换正式输出目录中的文件。

`work_dir/project.normalized.json` 保存绝对路径、源元信息、计算时长和映射后的成片字幕。每条的 `work_dir/jobs/<id>/final/` 或 `sample-<N>s/` 保存背景、开场背景、ASS、字体副本、短文件名过滤器、两遍响度测量统计、命令 JSON、日志及结果 JSON。正式与样片汇总分别为 `render-results.json` 和 `sample-results.json`。

音频先按保留区间剪切，切口有 5 毫秒短淡入淡出，再执行 loudnorm 首遍测量和携带实测值的第二遍处理；目标为 −16 LUFS、LRA 11、−1.5 dBTP。末尾使用 `aresample=48000,asetpts=N/SR/TB` 重建连续音频时间戳。静音或无效测量会报错。编码线程上限为 2，复杂过滤器线程为 1。

渲染成功只表示命令完成。交付前仍应执行独立完整解码、时长、编码、峰值、字幕和画面核查，并对操作过程与原声做人工复核。
